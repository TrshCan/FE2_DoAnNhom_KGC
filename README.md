# ⚛️ React + Vite Starter

Welcome to your minimal React + Vite project! This template is pre-configured with Hot Module Replacement (HMR) and essential ESLint rules to get you developing fast and clean.

---

## 🚀 Features

- ⚡️ Powered by [Vite](https://vitejs.dev/) – lightning-fast dev server
- 🔥 Hot Module Replacement (HMR)
- ✨ Minimal configuration
- 🧠 ESLint-ready
- 🛠 Two plugin options:
  - [`@vitejs/plugin-react`](https://github.com/vitejs/vite-plugin-react) (Babel-based)
  - [`@vitejs/plugin-react-swc`](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) (SWC-based)

## ▶️ How to Run the Project

Follow these steps to get your development environment up and running:

### 1. 📥 Pull the Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```

### 2. 📂 Navigate to the Project Folder

```bash
cd your-repo-name
```

### 3. 📦 Install Dependencies

Make sure you have Node.js installed, then run:

```bash
npm install
```

This installs all the necessary packages listed in `package.json`.

### 4. 🧪 Start the Development Server

```bash
npm run dev
```

Vite will start a dev server and show a local URL (typically `http://localhost:5173`).

### 5. 🌐 Open in Browser

Copy the link shown in the terminal and paste it into your web browser.
